# Phase 03 Plan 01: Training Catalog And Annotation UI

## Goal

Create the portable data contracts and reusable modules needed to prepare
multi-speaker, emotion-aware, environment-aware training runs without claiming
that unavailable AI processors have executed.

## Tasks

1. Add synchronized light/dark theme tokens and app-level theme persistence.
2. Add project Training Catalog persistence and media annotation endpoints with backend tests.
3. Add Speaker Isolation to Speech to Text and word-level speaker/emotion tagging to Script.
4. Add per-asset speaker/emotion controls to Media Pool.
5. Replace Recorder on Voice Training with Train and make Voice Vault create Speaker Profiles.
6. Add checkpoint, denoise, and multi-asset Environment Noise Profile settings.
7. Run frontend/backend tests, build, and browser QA; update handoff artifacts.

## Verification

- Catalog survives API restart and project moves using project-relative storage.
- Light/dark theme changes every module surface without mixed Recorder/Timeline colors.
- Training manifest contains no Recorder.
- Asset and word annotations persist and reload.
- Checkpoint interval defaults to 1,000.
- Automatic diarization/isolation/training buttons clearly report unavailable adapters.
