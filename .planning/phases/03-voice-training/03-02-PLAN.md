# Phase 03 Plan 02: Verified Dataset Compiler And Forced Alignment

## Goal

Turn only the footage explicitly selected by the user into a deterministic,
portable Dataset Manifest with verified text, timings, speaker ownership, and
emotion context. Do not start fine-tuning in this plan.

## Preconditions

- Plan 03-01 contracts and UI are complete.
- Selected media source and `analysis.wav` paths are project-relative.
- Speaker Profiles exist before mixed-speaker material can become ready.
- A known script may skip ASR, but it may not skip alignment/validation.

## Tasks

1. Define a Dataset Compiler port and a project adapter without importing
   OmniVoice implementation classes into API routes or UI modules.
2. Define a versioned Dataset Manifest with source asset ID, project-relative
   audio reference, segment start/end, verified text, Speaker Profile ID,
   Emotion Label, quality status, and provenance.
3. Compile only `trainingSelected` assets and reject missing audio, empty text,
   invalid timing, unassigned mixed-speaker spans, or dangling profile IDs.
4. Add a forced-alignment/validation adapter for supplied reading scripts. Show
   omissions, repetitions, substitutions, timing coverage, and confidence
   instead of silently marking the source ready.
5. Segment assets from exact word timings while preserving file-level defaults
   and word-level speaker/emotion overrides.
6. Persist immutable compiler output under a project-owned dataset/job folder;
   never store workstation-absolute paths.
7. Surface readiness, validation failures, selected-source count, speaker
   coverage, and generated segment count in Train/Training Job.
8. Add backend contract tests, frontend readiness tests, portability tests, and
   mixed-speaker/known-script error cases.

## Verification

- Selecting two of three footage files compiles only those two.
- Moving the project folder does not invalidate the manifest.
- A known script with changed or skipped words is flagged before compilation.
- Mixed footage cannot become ready while spoken spans lack speaker ownership.
- Word-level emotion and speaker overrides survive segmentation.
- Re-running unchanged inputs produces the same semantic manifest.
- No OmniVoice training process or fake checkpoint is started by this plan.

## Handoff To Plan 03-03

Plan 03-03 will consume only a validated Dataset Manifest and connect
project-native OmniVoice job execution, progress, cancellation, periodic
checkpoints, recovery, and model lineage.
