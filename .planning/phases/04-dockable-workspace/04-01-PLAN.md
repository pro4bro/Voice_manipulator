# Plan 04-01: Dock Contract And Migration

## Objective

Introduce the validated six-zone schema and reusable `DockLayout` / `WorkspaceSession` seams without changing audio-processing behavior.

## Steps

1. Inventory current module inputs, subscriptions, page assumptions, and lifecycle coupling in `workspaceManifest.ts` and `ModuleRegistry`.
2. Define typed `ModuleDefinition`, `DockLayoutState`, `DockZoneId`, `DockTabStack`, and a versioned project-layout migration. Add the `lip-sync` route and default layout, but make no processor-success claim.
3. Implement a compatibility adapter that presents current three-column manifests through six zones; migrate one existing page first, then the remaining pages.
4. Run a maintained-library spike for pointer/keyboard dragging and split resizing against the real Studio page. Select only after touch/pointer reliability, keyboard control, no unwanted text selection, and no global scroll pass.
5. Move transient service ownership into `WorkspaceSession`, so a running recording/job/playback service is independent of visual panel placement.
6. Implement schema, interaction, accessibility, portability, and active-job regression tests from `04-CONTEXT.md`.

## Module boundaries

| Module | Owns | Does not own |
| --- | --- | --- |
| DockLayout | docking, snap targets, tabs, split sizes, layout repair | media, jobs, engine calls |
| ModuleRegistry | definitions and renderer lookup | position, drag state, engine paths |
| WorkspaceSession | selection, commands, subscriptions, playback/job lifecycle | dock coordinates, engine internals |
| Engine adapter | validated processor invocation and diagnostics | UI state or layout |

## Completion gate

All existing pages work through the new shell, the fourth page appears with the LipSync default layout, and moving any module cannot sever its shared data, job, recording, or playback wiring.

## Deferred deliberately

Arbitrary free-floating module windows, cross-project layout sharing, and desktop multi-window behavior wait until bounded docking is proven and Phase 07 packages the stable shell.
