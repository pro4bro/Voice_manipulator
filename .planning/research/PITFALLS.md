# Pitfalls

- Do not copy page markup three times; compose the same modules with capability flags.
- Do not expose OmniVoice classes in route or frontend types.
- Do not claim isolator/changer/dubber processing works before a real adapter and verification asset exist.
- Do not allow hidden popup content to create workspace overflow.
- Do not store media blobs in project metadata JSON.
- Do not let model caches fall back to user-global directories.
- Do not couple desktop packaging to the first UI architecture milestone.
