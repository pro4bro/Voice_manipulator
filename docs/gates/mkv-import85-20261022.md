Scope: UI-09. Owner asks which tool handles Live Transcribe and requests the normal
Import dialog for MKV with its extra options retained. ADR0133 records the UI and
unchanged callback/model boundaries.

## Evidence and change

a context menu. Cache choice required another dialog. Four red regressions catch
the absent automatic standard review (`.scratch/import85/dialog-red.log`).

LocalMediaImportDialog now owns one review: cache/link, per-track Import/STT,
ordinary Import, plus a MKV-only follow section. Selection does not start work;
Import passes the chosen cache value, Follow retains the existing60s callback and
selected-track behavior. The existing Workspace controller and API stay authoritative.

is excluded. Cache survives controlled track updates on the same source.

Cancel button/backdrop/Escape withdraw pending selection. Initial enabled focus,
Tab wrapping and focus restoration retain keyboard access. Scrollable tracks,
wrapped filename/footer and existing style tokens keep the standard presentation.
No backend, media, inference, dependency or persistent-format changes.

Browser upload still shows its queue dialog and can hand off to native selection
for a growing MKV. Copy now describes the automatic review. Workspace's follow
notice describes automatic final import and optional full-file STT instead of
instructing users to always press Finish after OBS Stop.
