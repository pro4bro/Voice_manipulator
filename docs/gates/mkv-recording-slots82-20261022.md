# Round82 — MKV recording slot indicators (2026-10-22)

Scope: STT-OBS-11. The owner requests visible recording/ready states on both
the followed parent slot and its child tracks. Presentation only; no backend,
engine, model, project-format or media changes. ADR0130 records the authority
and distinction between provisional capture and complete imported media.

## Implemented

- Unfinalized followed-MKV parent: a red pulsing circle replaces the Import tick,
  with45-degree red-tinted stripes moving left-to-right on its slot and each track.
- Native Import controls remain keyboard-operable; checked/mixed circle is filled,
  withdrawn Import is hollow. Selection handlers, current values and other stages
  remain intact. Busy/description semantics and compact status text expose state.
- The existing parent's `source-final.mkv` publication returns all tracks to normal
  controls/appearance. A child still running STT cannot prolong recording styling.
  The existing workspace asset refresh supplies the transition without reload.
- No guessed duration, silence, file-size timer or extra polling is introduced.
  Recycled footage and ordinary MKV imports are excluded. Reduced-motion preserves
  static state cues and disables both animations.
