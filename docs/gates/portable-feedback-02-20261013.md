from that source. This durable owner preference was saved through OpenViking

The main app had the same defects as the portable:

- Failed unpublished OBS journals were displayed outside the normal asset
  rows, so they lacked context-menu/recycle actions. Stopped journals now have
  Open, Retry MKA and Move to Recycle Bin, plus reachable OBS bin Restore and
  confirmed permanent deletion. PCM is retained by recycle/restore; active
  capture/finalization/archive/STT work prevents removal. Deleted journals
  cannot resume or publish until restored. Published footage retains its
  existing asset actions.
- Hiding siblings in single-track view left sibling playback elements mounted;
  local mixer state was lost when Timeline mounts changed. Selected tracks now
  own the playback elements and matching Script rows; detached players pause,
  delayed imported-player activation is fenced, and gain/Mute/Solo state lives
  in the project session. S is below M; Solo is additive within the selected
  footage and Mute wins. Source audio and processing gain/STT/training are
  unaffected by preview controls.
- Real browser verification found a second selection defect after component
  tests passed: Ctrl-selecting two children was replaced with their parent by
  Media Pool's opened-prop synchronization, producing three players. A
  controlled `selectedScriptAssetIds` prop now preserves the exact subset.
  The actual two-way Workspace synchronization harness failed before the fix
  and passes after it.
- Voice Collection now exports/imports a per-entry verified ZIP. LoRA, full
  checkpoint and RVC payload shapes include their referenced checkpoint,
  adapter/index, reference audio, consent and lineage. Base/runtime are excluded.
  Import stages and verifies relative paths, file inventory, size/hash and
  lineage, rejects links/collisions/unsafe members, and cleans up failures.
  Limits:8GiB expanded/20,000files/16MiB metadata; upload8GiB+80MiB. Entry IDs
  are allocated at the destination; standalone project import does not invent
  coordinated Model Set publication. See VOICE-COLLECTION-TRANSFER.md.
