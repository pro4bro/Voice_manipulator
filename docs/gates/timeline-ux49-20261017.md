# Round49 — viewport navigation and timing/clipping overlays

Date: 2026-10-17. Owner UX feedback; one bounded stabilization round. ADR0106.

## Implemented

- Ordinary canvas, imported virtual windows and archived OBS scrubs use elapsed
  animation time at 10% viewport width per second in the outer 10% edge zones.
  Keep fractional position so browser pixel rounding cannot change the rate.
- Zoom buttons/slider center the current playhead and clamp source boundaries.
  Live OBS follow and full-duration seek surfaces retain their own contracts.
- Plain blank waveform/subtitle clicks clear timed selection. Actual word,
  Ctrl/Meta selection, insertion, stretch and edit gestures retain their roles.
- Shared numeric selection overlay: accent fill alpha0.30, opaque accent numbers,
  no gray panel or visible names, outside IN/OUT for narrow intervals, centered
  duration and collision-safe rows including viewport edges. Imported/OBS labels
  preserve source times and source ID/revision guards.
- Clipping ranges use only contiguous over-threshold peak buckets. No quiet-gap
  bridge, maximum-range coalescing or minimum-width expansion. One nonzero SVG
  fill prevents opacity accumulation. Archived waveform/clipping share i/N
  bucket-start coordinates.
- Preferences checkbox “Tự ẩn highlight quá âm lượng sau 5 giây” is machine-local,
  defaults off, roundtrips through API and reaches every Timeline view. Timer
  stays mounted across archived waveform refreshes; stale windows hide separately.

UAT remain separate. This round makes no linguistic STT accuracy claim: independent
word IN/OUT listening anchors from round48 remain unmeasured. Phase03 stays60%,
