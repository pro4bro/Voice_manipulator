# VM-DELIVERY-01 — delivery capability preflight (partial)

Date: 2026-10-15. Status: partial implementation; delivery quality gate remains open.

Product integration: route registered; Script exposes a capability report before
generation. Neutral/default settings are normalized consistently in frontend and
backend; unsupported requests still fail before engine use. A regression exercises
the actual Script planning/job path with a fake engine and checks no inference
on whisper. This is control-path evidence, not a real whisper artifact.

This slice adds a read-only Voice Script capability report. It resolves the
current clip/segment/sentence settings and gives every row a stable ID, selected
voice, readiness state, blockers, and a requested/effective/method/reason report
for delivery, mood, emotion, intensity, gain, and note.

The report recognizes only `delivery=neutral` and `emotion=normal` as the
selected project voice's unmodified default. It does not claim that an engine
control was applied. Whisper, shout, other emotion labels, free-form mood, and
intensity remain unsupported. Intensity is never converted to gain. Gain is
reported as a separate unimplemented render setting and blocks this preflight;
notes remain Script metadata and do not block it. Missing voice assignment is
also blocked.

The endpoint is exposed by `make_voice_delivery_router()` at
`POST /api/voice-script/delivery-capabilities`; it accepts the Script document
directly and does not write project files or invoke an engine. The application
still needs to register the router. Integration must also make the generation
path treat explicit neutral settings as the default/no-conditioning case; the
existing `VoiceScriptSpeaker._plan` currently rejects any non-empty synthesis
setting, including neutral. Keep generation blocked for unsupported requests.

Automated tests cover inherited settings, unknown emotion labels, unsupported
delivery/intensity, gain separation, note-only/neutral-only readiness, missing
voice, and the read-only route response. These tests establish capability
reporting only. They do not prove that whisper, shout, mood, or emotion can be
conditioned while retaining trained/clone identity. A real same-speaker A/B at
normalized audition level, with audio and identity evidence, remains required
before any specific delivery control can be called supported.
