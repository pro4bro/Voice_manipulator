Root integration uses the current Script/edit revision and only publishes a
verified artifact. The Script panel reports measured RMS/peak and requested vs

pointer restores after move/Open Existing only while its lineage still matches.

This is actual processing of prior speech, not fresh inference or distinct-human
identity evidence. Current focused checks and final build are in the combined gate.

`render_loudness(source, destination, regions, global_gain_db)` accepts only WAV
PCM16 mono 24 kHz. It preserves the source and exact frame count, rejects
overlapping/out-of-order regions and invalid frame/gain values, and writes the
destination atomically. Region gain and global gain add in dB. Each region uses
one scalar gain, limited against measured peak headroom at -1 dBFS. For Script
settings, sentence gain overrides segment gain (segment locks block sentence
gain), then the clip-level gain is added once globally. Clip gain locks block
descendant gain overrides. An inherited clip gain is never also passed as a row
gain. An explicit global gain of zero preserves source level. If quantization
would exceed PCM range, the processor fails before publishing instead of
silently limiting samples.

For a gain transition, a 5 ms linear-amplitude ramp is applied at the region
boundary only when the adjacent 5 ms source window contains nonzero samples.
This is a short automation ramp, not dynamic compression. Reports include
requested/applied gain, headroom decisions, start/end ramp frames, sample RMS
dBFS and peak dBFS. RMS dBFS is sample RMS; no LUFS measurement is claimed.
