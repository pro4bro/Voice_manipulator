# VM-REF-LIB-01 — 2026-10-15

Reference tab in the Manipulator library lists project footage and audio tracks,
supports multi-file browser import and the existing native track-import flow,
Ctrl/Shift selection, keyboard/right-click batch mark/unmark, reference badges,
filtering and explicit lazy audio preview. It includes existing assets regardless
of their STT/training/import tick. Selecting rows never decodes audio.

Reference is a separate persisted asset role. Atomic batch validation rejects
missing, disabled/deleted assets and mixed-container parents before writing;
users choose a real imported audio track. Unmarking preserves files, transcript,
training/STT selection and later bindings. No source duplication or automatic
voice-identity change is introduced. Feature extraction is deferred to resolver
rounds; marking an asset does not claim measured reference characteristics.
