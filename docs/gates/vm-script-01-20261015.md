# VM-SCRIPT-01 — 2026-10-15

## Delivered

Script now owns a clip → segment → sentence document in
`scripts/voice-over.json`, with portable IDs, provenance/tags, per-level delivery
intent and ancestor locks. Legacy browser rows migrate without changing row IDs.
Saves serialize, retain edits made during an in-flight write and use optimistic
revision checks; a stale window cannot overwrite a newer saved document. Loading
an existing project restores its document independently of browser storage.

The Script exposes scope controls, sentence splitting, joining compatible
sentences and regrouping sentences into segments. Intl sentence segmentation
is verified for Vietnamese, English, Chinese, Japanese and Korean. Split retains
the exact text; join preserves provenance/tags and refuses incompatible voice,
segment or settings. Reading outputs retain sentence metadata for later reopening.

Duration, emotion/mood/intensity, whisper/shout, gain and note are editable intent.
The UI labels their pending synthesis support; unsupported synthesis direction
is rejected before inference rather than silently generating unchanged speech.
Actual duration/delivery/gain rendering belongs to the later named rounds.
