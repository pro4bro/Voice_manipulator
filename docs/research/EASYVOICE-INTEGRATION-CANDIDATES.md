# EasyVoice integration candidates for PRO4BRO

Reviewed 2026-10-12. EasyVoice is pinned to `XavierChuu/EasyVoice`
`af299a5cce44c6f877047bff54496fc1a823c090`. This is an implementation and
license screen, not a claim that any candidate sounds or performs better.

## Recommendation

For an early comparison, use the existing **faster-whisper Small** option after
installing its weights; the current portable cache includes Tiny, Base, Medium
and Large-v3 but not Small. Then
prioritize a small, isolated **Demucs vocal-separation prototype**. Consider
**F5-TTS + ViVoice** as a private Vietnamese TTS research option if the goal is
to compare generation quality; its model terms are non-commercial, so it is not
a default distributable model. Treat Vocos as an F5 dependency, not a separate
generator choice. Defer WavLM and a second RVC implementation: both overlap
with existing PRO4BRO paths and would add another engine/checkpoint lineage
before a clear gap is demonstrated.

## Benchmark protocol to make the comparison useful

- **Vietnamese TTS:** compare OmniVoice with ViVoice/F5 using the same held-out text, reference speaker clips and reference transcript. Record Vietnamese CER from one fixed recognizer, blind human ratings for intelligibility/naturalness/prosody, speaker similarity, duration drift, cold load, warmed real-time factor, peak RAM and VRAM. Keep output sample rate and post-processing identical. F5 Base is not a Vietnamese contender; compare it only on a separate shared English/Chinese set.
- **STT:** Small is already available. Run the same frozen audio and human transcript through Small, Medium and Large-v3; report CER/WER, word-timing IN/OUT error where available, RTF, cold-load and peak memory. The model-size trade-off is a result, not a controlled same-model comparison.
- **Vocal separation:** on known-mixture stems, report SDR/SI-SDR and runtime/peak memory; on real project audio, add blinded listening for leakage, artifacts and speech intelligibility. Preserve source audio and register each stem as a derivative with source/sample-rate/channel metadata.
- **RVC:** compare engines only with one compatible trained voice artifact, identical source PCM, F0 extractor, block/chunk size, index/protect/pitch parameters and device. Report CER, speaker similarity, end-to-end latency p50/p95, underruns, RTF and peak VRAM. A different checkpoint or model family is a separate experiment.
- **Diarization / embeddings:** evaluate the same multi-speaker clips with reference speaker turns and report DER plus speaker-attribution confusion, along with runtime and memory. Do not treat the EasyVoice code's chosen window/hop or its model card as an accuracy result.

These metrics define an experiment; they are not results. EasyVoice's benchmark report template was empty in the inspected revision, and no paired inference was performed here.
